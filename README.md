# turtle_body
The 3D design files that make up the components of the hope turtle's body.  

**Turtle Body** is the open-source mechanical design repository for the [Hope Turtle Project](https://hopeturtles.org): a wind-powered, largely organic marine vessel designed to carry food, building materials, love and hope toward coastal destinations. It is the physical counterpart to [TurtleOS](https://github.com/h2h-project/turtleOS), which handles sensing and autonomous navigation; the TurtleShell PCB, which connects and powers the electronics; and [HopeTurtles.org](https://github.com/h2h-project/hopeTurtles.org), which supports building, mission planning, tracking and discovery reporting. Together, these parts are intended to make Hope Turtles practical to reproduce, study and improve anywhere in the world.

This repository contains the parametric OpenSCAD models and fabrication files used to build the turtle body, including its bottle interfaces, control cap, rotating sail cage, magnetic angle-sensing shaft, bearing surfaces, sail battens and crossbars, chassis connections, rear fin and ballast components. The designs are being developed around ordinary bottles, locally available wooden boards and accessible 3D printing, with core measurements—such as bottle diameter, wood thickness, running clearance, hole size and component spacing—kept adjustable wherever possible. Source `.scad` files are retained as the editable designs from which printable STL models and other fabrication outputs can be generated.

The Turtle Body models are also intended to become the geometry engine behind a body generator on [HopeTurtles.org](https://hopeturtles.org). A builder will be able to enter the measurements of locally available bottles, boards and hardware, and the generator will use the parametric designs in this repository to produce a compatible set of body parts and fabrication files. Until that workflow is fully connected, this repository serves as the source of truth for the evolving mechanical system; once integrated, improvements made here can flow into the public generator so that each new iteration becomes easier for other builders to reproduce and adapt.
